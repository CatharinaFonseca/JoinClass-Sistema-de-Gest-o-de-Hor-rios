# 📚 Sistema de Gestão de Horários

Sistema desenvolvido para gerenciar horários acadêmicos de forma eficiente.

## 🚀 Tecnologias
- C#;
- .NET;
- Entity Framework;
- PostgreSQL;
- HTML5;
- CSS;
- JavaScript.
  
## 📌 Funcionalidades
- Cadastro de usuários
- Gerenciamento de horários
- Controle de Disponibilidade
